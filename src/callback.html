Finish authorization {% include "edit-icon.html" %}

The user should now have returned from Twitter having authorized access to their account. A request_token is a short-lived one time use value so if it is invalid users will have to start the authorization flow over.

Bootstrapping

Set up as before but hold off on the TwitterOAuth instance.

require 'vendor/autoload.php';
use Abraham\TwitterOAuth\TwitterOAuth;

define('CONSUMER_KEY', getenv('CONSUMER_KEY'));
define('CONSUMER_SECRET', getenv('CONSUMER_SECRET'));
define('OAUTH_CALLBACK', getenv('OAUTH_CALLBACK'));

Sessions

Pull the temporary oauth_token back out of sessions and clear it immediately since it is single-use. If the oauth_token or oauth_verifier is missing, or if the oauth_token does not match the one you sent to Twitter, abort the flow and don't continue with authorization. 

$request_token = [
    'oauth_token' => $_SESSION['oauth_token'] ?? null,
    'oauth_token_secret' => $_SESSION['oauth_token_secret'] ?? null,
];
unset($_SESSION['oauth_token'], $_SESSION['oauth_token_secret']);

if (
    !is_string($request_token['oauth_token']) ||
    !is_string($request_token['oauth_token_secret']) ||
    !isset($_GET['oauth_token'], $_GET['oauth_verifier']) ||
    !is_string($_GET['oauth_token']) ||
    !is_string($_GET['oauth_verifier']) ||
    !hash_equals($request_token['oauth_token'], $_GET['oauth_token'])
) {
    // Abort! Something is wrong.
    http_response_code(400);
    exit;
}

Finish bootstrapping

Now we make a TwitterOAuth instance with the temporary request token.

$connection = new TwitterOAuth(CONSUMER_KEY, CONSUMER_SECRET, $request_token['oauth_token'], $request_token['oauth_token_secret']);

Get access_token

At this point we will use the temporary request token to get the long lived access_token that authorized to act as the user.

Request 
$access_token = $connection->oauth("oauth/access_token", ["oauth_verifier" => $_GET['oauth_verifier']]);
Response Cached

Credentials storage

This is the important part where you save the credentials to your database of choice. 

session_regenerate_id(true);
$_SESSION['access_token'] = $access_token;

You now know the users identity and can start interacting with their Twitter account.
